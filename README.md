## 📊 실전 매매 & 수익률 관리 원칙

1. **장전 알람 종목**: 알람 발행 후 당일 **09:00 시가(Open Price)**를 매수가로 체결 등록
2. **장중/야간 알람 종목**: 알람 시점의 **시가/체결가**로 진입
3. **실시간 시세 연동**: 네이버 증권 및 야후 파이낸스 실시간 시세 API로 현재가 및 미실현 손익 실시간 계산
4. **목표가 / 손절가 매도 처리**: 목표가 돌파 시 **"익절 매도완료"**, 손절가 이탈 시 **"기계적 손절매"**로 자동 상태 전환 및 실현 손익 확정
5. **일일 & 누적 수익률**: 당일 체결분 일일 수익률 및 포트폴리오 누적 수익률 자동 관리

## 🚀 빠른 시작

### 1) 로컬 간이 서버 실행 (권장)
```bash
./serve.py
# 또는 python3 serve.py
```
- 브라우저(`http://localhost:8080`)에서 실시간 대시보드가 열립니다.
- 상단의 **[시세·수익률 재계산]** 버튼으로 실시간 주가와 수익률을 즉시 갱신할 수 있습니다.

### 2) 상태 데이터 수동 동기화
```bash
./update_status.py
```
